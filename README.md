# Heart-disease-prediction-app
This project is a web-based application built  that predicts the presence of heart disease based on user-provided medical data. It uses a machine learning model trained on real-world health data to assist in early detection and awareness.
📌 Features
Predicts heart disease based on 13 health indicators
Trained with multiple ML algorithms — best accuracy from XGBoost
Simple and interactive web interface using HTML & CSS
Google Sheets integration to log inputs and predictions
Deployed using Flask for a lightweight backend

📁 Dataset
The model is trained using the Heart Disease Dataset from Kaggle (heart.csv)

🚀 Technologies Used
Python, Flask
Scikit-learn, Pandas, NumPy, XGBoost
HTML, CSS
Google Apps Script (for Sheets logging)
